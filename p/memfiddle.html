MemFiddle

Posted on 11/21/2026
Tags: Programming, Tools
In my Poop App story, I used ChatGPT to one-shot a quick web app to solve a real-life problem. To do this on my phone, I needed to use the Working Copy app to combine and load HTML, CSS, and JavaScript in a web browser.

For this use case, I haven't been satisfied with this dependency. Working Copy is a full git client and requires the user to organize projects into git repositories. It's got a learning curve and it's overkill when you just want to write or generate a quick web app on the go.

Inspired by JSFiddle, I wondered if it'd be possible to make a mobile-optimized experience where I can paste in HTML, CSS, and JavaScript (generated by my favorite LLM) and run that mini web app with ease.

It is possible! Introducing MemFiddle, a way to preview and test simple web apps right in your web browser. You can also add MemFiddle to your home screen as a PWA.

To get started, prompt your favorite LLM (such as ChatGPT) to give you 'HTML, CSS, and vanilla JavaScript with no dependencies' and then paste the resulting file content into MemFiddle.

Here's an example prompt:
I want you to create a simple web app where the user can tap the screen and a poop emoji will fly up from the bottom of the screen, with some random spin and velocity, then fall down with gravity. Make the background of the page black. Support multi-touch. Give me HTML, CSS, and vanilla JavaScript with no dependencies.
MemFiddle runs entirely in your browser and has no server component (beyond the web server hosting its static files), so there is no way to directly share the mini web apps you create.
